## Definition of Done
A phase is complete only when:
- Feature works end-to-end.
- Feature uses shared services.
- Data is persisted correctly.
- Errors have graceful UI states.
- Tests cover critical logic.
- Documentation is updated.
- Existing features still work.

## Product Rule
Do not add a feature merely because it uses a fashionable technology. Add it only if it improves discovery, understanding, personalization, or usability.
